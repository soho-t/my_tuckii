隱私權政策與合規揭露

最後更新日期：2026 年 11 月 24 日

感謝您使用 隨手存 MyTuckii（包含 Android 應用程式與電腦網頁伴侶版，以下簡稱「本服務」）。本服務採「本機優先、零第三方伺服器」設計，我們高度重視您的資料主權與隱私安全，特此說明資料的存取、儲存與保護方式。

一、零後端伺服器與資料儲存位置

  • 本機儲存：您收藏的網頁連結、文字筆記、標籤、螢幕截圖與文件，預設全部儲存在您裝置本機資料庫中。
  • 無開發者伺服器：開發者未架設任何後端資料庫，不會蒐集、上傳、出售或監控您的個人資料與收藏內容，也不內嵌第三方廣告追蹤器。

二、Google 帳號登入與 Google Drive 同步權限

當您主動開啟跨裝置雲端同步或使用電腦網頁伴侶版時，本服務會向您請求授權以下最小必要權限：

  • https://www.googleapis.com/auth/drive.appdata：僅用於存取您個人 Google Drive 內的隱藏應用程式專屬資料夾（appDataFolder），以讀寫本服務產生的同步索引檔與附件。
  • 嚴格隔離：本服務無法瀏覽、讀取、修改或刪除您 Google Drive 雲端硬碟中的其他任何個人檔案或資料夾；開發者也無法存取您的雲端同步資料。
Google API 有限使用聲明（Limited Use Disclosure）：
隨手存 MyTuckii 對從 Google API 接收之資訊的使用與傳輸，完全遵守 Google API 服務使用者資料政策 （包含「有限使用」要求）。所存取之資料僅用於提供跨裝置同步功能，絕不用於廣告投放或訓練 AI 模型。

三、AI 智慧整理功能（Gemini API）

  • 個人自備金鑰（BYOK）：AI 功能預設為關閉狀態。您需自行向 Google AI Studio 申請個人 Gemini API Key 並填入設定頁；該金鑰僅儲存於您的手機本機，不會回傳給開發者。
  • 按需傳輸：僅在您主動開啟自動整理或點擊 AI 摘要／識圖／智慧搜尋按鈕時，應用程式才會直接將該筆文字或截圖傳送至 Google Gemini API 處理。

四、裝置權限與網路請求說明

  • 剪貼簿與快速收錄：僅在您手動開啟「開啟時偵測剪貼簿連結」、點擊通知欄按鈕、快速設定磚或桌面小工具時讀取剪貼簿，用於快速建立收藏。
  • 增強預覽與連結健康檢查：開啟上述功能時，裝置會直接向您收藏的公開網址發送 HTTP 請求以抓取標題、封面圖或確認連結是否失效，過程不經開發者伺服器。
  • 通知權限：僅用於本機排程的每日回顧、久未看提醒、週末提醒及常駐剪貼簿快捷通知，無雲端行銷推播。

五、資料備份與徹底刪除權利

  • 資料匯出：您可隨時透過 App 設定頁「匯出備份」將所有資料與附件打包為離線 ZIP 檔帶走。
  • 一鍵徹底刪除：您可隨時在 App 設定頁點擊「刪除帳號與資料」，立即清空個人 Google Drive 隱藏資料夾內的同步檔、刪除本機所有收藏與附件並解除帳號綁定。
  • 撤銷 Google 授權：您亦可隨時前往 Google 帳戶第三方存取權限管理 移除本服務授權。
