\# 隨手存 MyTuckii



\*\*隨手存（MyTuckii）\*\* 是一款專為 Android 打造的\*\*離線優先（Offline-First）跨裝置個人收藏庫\*\*。無論是瀏覽器網頁、社群貼文、螢幕截圖、靈感筆記還是手機本機文件，都能隨時一鍵收錄，並透過你個人的 Google Drive 隱藏專屬空間跨裝置同步。



👉 \*\*\[前往 Releases 下載最新 Android 安裝檔（APK）](https://github.com/soho-t/my\_tuckii/releases/latest)\*\*



\---



\## ✨ 核心特色



\### 1. 多元收錄與極速快捷

\- \*\*系統分享選單整合\*\*：支援從任何 App 點擊「分享」直接收入文字、網址、單張／多張截圖與各類文件（PDF / Word / Excel 等）。

\- \*\*系統級一鍵存剪貼簿\*\*：

&#x20; - \*\*剪貼簿常駐通知\*\*：通知欄常駐快捷按鈕，在社群或購物 App 複製連結後點擊即可收錄並自動退回原畫面。

&#x20; - \*\*Android 快速設定磚（Quick Settings Tile）\*\*：下拉快速設定面板點選「存進隨手存」立即收錄。

&#x20; - \*\*桌面小工具（Home Screen Widget）\*\*：在手機桌面放置「存剪貼簿」圓角按鈕，隨時點擊存入。

&#x20; - \*\*開啟自動偵測\*\*：打開 App 時自動偵測剪貼簿新連結並提示一鍵收藏。

\- \*\*增強預覽\*\*：存入網址時自動在背景抓取公開網頁標題、摘要與 OG 封面縮圖。



\### 2. 隱私優先與跨裝置同步

\- \*\*完全離線可用\*\*：所有資料優先儲存於手機本機 SQLite（Drift）資料庫，無網路也能流暢搜尋與瀏覽。

\- \*\*Google Drive 專屬空間同步\*\*：綁定個人 Google 帳號後，資料加密同步至你個人雲端硬碟的隱藏專屬資料夾（`appDataFolder`），開發者無法存取。

\- \*\*離線完整備份與匯入\*\*：支援將所有收藏、收藏夾、標籤與本機檔案打包為離線 ZIP 備份還原，並支援匯入 Chrome / Edge / Safari 匯出的 HTML 書籤檔。



\### 3. ✨ AI 智慧整理（BYOK 自帶金鑰模式）

\- 支援填入個人免費的 \*\*Google Gemini API Key\*\*（金鑰僅儲存於手機本機，採用 `gemini-2.5-flash` 模型）。

\- \*\*自動標籤與歸類\*\*：新增收藏時自動產生 2～4 個繁體中文標籤，並比對現有收藏夾自動歸類。

\- \*\*批次整理\*\*：提供「一鍵整理所有無標籤收藏」功能，快速梳理既有資料。



\### 4. 🔔 智慧回顧與連結健康檢查

\- \*\*滑卡片複習模式\*\*：仿卡片滑動介面，快速瀏覽並標記已讀未讀項目。

\- \*\*每日回顧推播\*\*：自訂每日提醒時間，預排未來 14 天不重複待讀收藏。

\- \*\*久未看與週末清單提醒\*\*：每週提醒整理超過指定天數（14 / 30 / 60 天）未讀項目，以及週五晚間清單提醒。

\- \*\*連結健康檢查\*\*：每週在 Wi-Fi 環境下自動檢測 YouTube、X（Twitter）、Spotify 與一般網頁連結，原作失效時自動標記 `#失效連結` 並通知。



\### 5. App 內自動更新檢查

\- 每日自動比對 GitHub Releases 最新版本（亦支援設定頁手動檢查），有新版時直接透過瀏覽器下載 `.apk` 覆蓋升級，免移除舊版、資料完整保留。

\## 📲 安裝與更新方式



1\. 點擊上方 \*\*\[Releases](https://github.com/soho-t/my\_tuckii/releases/latest)\*\* 下載最新的 `MyTuckii\_vX.X.X.apk`。

2\. 在 Android 手機開啟該 `.apk` 檔案完成安裝（若為首次安裝，請依系統提示允許「安裝未知應用程式」）。

3\. 日後發布新版本時，直接下載新版 `.apk` 覆蓋安裝即可，本機資料庫與設定皆會完整保留。

\## 🛠️ 技術架構



\- \*\*前端框架\*\*：Flutter（Dart）

\- \*\*本機資料庫\*\*：Drift（SQLite）

\- \*\*原生 Android 整合\*\*：Kotlin（`TileService` 快速設定磚、`AppWidgetProvider` 桌面小工具、`ClipboardManager` 焦點剪貼簿讀取）

\- \*\*雲端與 AI 服務\*\*：Google Sign-In / Google Drive API（`appDataFolder`）、Google Gemini REST API（BYOK）

\- \*\*自動化建置與發布\*\*：GitHub Actions（自動簽章編譯 APK / AAB 並發布至 GitHub Releases）

\## 🔒 隱私權聲明



\- 本應用程式不設有開發者後端伺服器，不會收集、上傳或追蹤任何個人收藏內容、剪貼簿紀錄或 API 金鑰。

\- 雲端同步檔案僅存放於使用者個人 Google 雲端硬碟的應用程式專屬空間；AI 整理功能由手機端直接連線至使用者自行設定的 Google Gemini API。
